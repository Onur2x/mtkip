MakinistTakip • Admin Paneli—

Excel'den kopyala → aşağıya yapıştır → SQL Üret → çıkan SQL'i Supabase > SQL Editor'de çalıştır.
Eşleşme: her PAR'a kendinden sonraki ilk BOS verilir (en fazla 3 saat içinde). Eşleşmeyen PAR/BOS uyarı olarak listelenir. Gece yarısı (00:xx) saatler en sona alınır. Tur süresi 51 dk sabit.
Dinlenme formülü: sonraki PAR − (BOS + (BOS − PAR)) → yukarı yuvarlanır. Örn: PAR 07:29, BOS 07:56, sonraki 08:45 → 08:45 − (07:56+27) = 22 dk. Son turun dinlenmesi 0 yazılır.
Dikkat: SQL önce o günün tüm satırlarını silip yeniler — günü tam yapıştır, parça yapıştırma.
